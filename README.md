# 旅プランスタジオ(2026.10.3–10.5)

2026年10月3日(土)〜5日(月)・2泊3日のカップル旅行を、4エリアのプランを切り替えながら手元でカスタムできる単一ファイルのブラウザアプリです。10/5(月)は誕生日で昼過ぎ帰路のため、誕生日ディナーはDay 2の夜に組み込む前提で設計しています。

旅行予約サービス風の3カラムUI(写真ヒーロー+日別タイムライン / 写真カードの候補プール / 料金サマリー)で、各施設・宿の写真は公式サイトおよびWikimedia Commonsから取得してファイル内に埋め込んであります(個人利用目的)。

## 使い方

`index.html` をブラウザで開くだけで動きます(ビルド・依存関係なし、完全自己完結・約1.4MB)。選択内容と旅のメモはブラウザ(localStorage)に自動保存されます。

## 機能

- **4プランのタブ切り替え** — 瀬戸内アート(直島・高松) / 鹿児島・指宿 温泉 / 道後・松山 湯めぐり / 沖縄・那覇 街歩きと海。4案フラットに同じ情報量で用意。
- **2泊3日タイムライン** — Day 3(10/5・月)は「昼過ぎ帰路・午前のみ」対応。詰め込みすぎると所要時間ベースで警告を表示。
- **アクティビティ候補プール** — 各エリア11件(サイクリング・シュノーケリング/マリン・ものづくり体験を全案に配置)。「+10/3〜10/5」ボタンで日程に追加/削除でき、月曜休館など催行不可の日はボタンが無効化。カテゴリ絞り込み対応。
- **Day 2夜の誕生日ディナー枠** — プランごとに3候補(料金・記念日対応の備考付き)から選択。
- **宿泊の選択式試算** — 各案に「手頃/中堅/記念日」の3グレードの宿候補(2026/10/3–4の実勢価格帯を調査、出典リンク付き)。プルダウンで選ぶと試算に反映され、金額は実予約額で上書き可能。
- **宿泊一体型の制約連動** — ベネッセハウスの「一扇」ディナーはベネッセ泊のときだけ選択可(それ以外はグレーアウト+「要: ◯◯泊」表示)。ベネッセ泊にするとミュージアム入館が宿泊者無料に自動切替。白水館・道後舘・朧月夜など2食付の宿は夕食を「宿泊プランに含む(¥0)」として二重計上を防止。宿を替えると依存するディナーは自動解除。
- **費用の自動試算** — アクティビティ・ディナー・宿の選択が2人合計/1人あたりに即時反映。交通費も編集可能。
- 各アクティビティ・ディナー・宿・料金に**公式情報源へのリンク**付き。
- ライト/ダークテーマ・モバイル対応。初期状態に戻すリセット付き。

## データの出典

料金・営業情報は2026年7月時点の調査(曜日確定＋休館日チェック＋各エリアのアクティビティ料金調査)に基づき、各カードから公式サイト等へリンクしています。「要確認」表示の項目(海況次第のマリン系、不定休の施設など)は予約時に公式へ確認してください。
