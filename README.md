# 旅プラン比較ボード（2026.10.3–10.5）

2026年10月3日（土）〜5日（月）のカップル旅行候補プランを、施設の休館日チェック結果とあわせて動的に比較できる単一ファイルのWebページです。

## 使い方

`index.html` をブラウザで開くだけで動きます（ビルド・依存関係なし、完全自己完結）。

## 機能

- **プラン比較** — 瀬戸内・直島 / 鹿児島・指宿 / 道後・松山 / 沖縄・那覇 の4プランを選択して並列比較。日別の行程ごとに「営業 / 休館 / 要確認」を自動判定し、プランごとの休館リスクを集計表示。
- **直島シミュレーター** — 訪問日（10/3・10/4・10/5）を切り替えると、地中美術館・李禹煥美術館・直島新美術館・ベネッセハウス ミュージアムの開館可否をその場で判定。
- **営業カレンダー** — 全施設 × 3日間の営業状況マトリクス。エリア絞り込み対応。各行に判定根拠（休館ルール）と公式情報源へのリンク付き。
- **アクションリスト** — 予約前に確認すべき事項（優先度タグ付き）。
- ライト / ダークテーマ両対応、モバイル対応。

## データの出典

各施設の判定は2026年7月時点の調査（曜日確定＋休館日チェック）に基づき、ページ内の各項目から内閣府・ベネッセアートサイト直島・各施設公式サイト等の情報源へリンクしています。営業時間・休館日は変更されることがあるため、予約直前に公式情報での再確認を推奨します。
